# Workers (Game Server)

Cloudflare Workers backend for multiplayer Coup. Manages lobbies, game rooms, and bot players via Durable Objects.

## Setup

```bash
bun install
```

## Development

```bash
bun run dev
```

Starts a local Wrangler dev server on `localhost:8787`.

## Deploy

```bash
bun run deploy
```

## Architecture

- `POST /api/rooms` creates a room (`{cid, bots?, autoStart?, rules?}` -> `{code}`).
- `GET /ws/game/:code` (WebSocket) joins it; one **GameRoom** Durable Object per code.

GameRoom uses the WebSocket Hibernation API and persists all state (roster, rules,
engine bytes, history) to DO storage after every change, so rooms survive eviction
and deploys. A single alarm drives paced bot moves, the 20s response timer,
auto-play for disconnected players (after 30s), lobby cleanup and room expiry.

Seats are bound to a secret client id (`cid`, generated by the browser and never
broadcast), not to display names. Bots receive a `BotView` with public info plus
their own hand only.

Requires `../wasm/coup.wasm` (`bash ../wasm/build.sh`, needs Emscripten).

## Key Files

```
src/
  index.ts          Entry point / router, room creation
  game-room.ts      GameRoom DO: lobby, game flow, narration, bots/timers via alarm
  bot.ts            Heuristic bots (easy / medium / hard) over a BotView
  engine.ts         WASM engine bridge (scratch-buffer, serializable state)
  types.ts          Protocol + constants (mirror in site/src/lib/types.ts)
```
